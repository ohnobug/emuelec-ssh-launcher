Portable ARM64 Dropbear SSH for EmuELEC. The original launcher was used on a XiFan XF45V V8-2 running stock 64-bit EmuELEC 4.7. The release verifies SSH key and password login under ARM64 emulation.

### Install

1. Download the **ARM64 ZIP** below and extract it on your computer.
2. [Set up your key or password](https://github.com/ohnobug/emuelec-ssh-launcher/blob/v0.1.0/docs/en.md#2-configure-login), then merge `ports` and `ports_scripts` into the games card root.
3. Connect the handheld to Wi-Fi. With your computer on the same LAN, launch **Ports → Start-SSH** and connect as `root` on TCP `2222`.

The release has no preset password. Use the key or password you configure when preparing the card.
