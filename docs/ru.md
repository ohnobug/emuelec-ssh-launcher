# Запуск SSH на портативной консоли с EmuELEC

Первую версию программы проверили на XiFan XF45V V8-2 со штатной 64-битной EmuELEC 4.7. На компьютере нужен SSH-клиент. Компьютер и консоль должны находиться в одной локальной сети.

## 1. Скачайте архив

Скачайте **ZIP для ARM64** из раздела [Releases → Assets](https://github.com/ohnobug/emuelec-ssh-launcher/releases/latest) и распакуйте его на компьютере. Для проверки сравните SHA-256 архива со строкой в `SHA256SUMS`.

## 2. Настройте вход

Имя пользователя — **`root`**, порт TCP — **`2222`**. В архиве нет пароля по умолчанию. Выберите способ входа.

**По ключу.** В отдельной папке на компьютере выполните `ssh-keygen -t ed25519 -f emuelec_ed25519`. Скопируйте `emuelec_ed25519.pub` в папку `ports/emuelec-ssh-launcher/` распакованного архива и переименуйте его в `authorized_keys` без расширения. Закрытый ключ `emuelec_ed25519` храните на компьютере.

**По паролю.** В терминале с OpenSSL (например, Git Bash или WSL) перейдите в корень распакованного архива. Выполните команду и введите выбранный пароль. Файл содержит хеш. Для SSH используйте пароль, введённый здесь. Пароли Wi-Fi и штатной системы задаются отдельно.

~~~sh
openssl passwd -6 > ports/emuelec-ssh-launcher/password.hash
~~~

## 3. Скопируйте файлы на карту с играми

Выключите консоль и вставьте **карту с играми** в компьютер. Скопируйте содержимое папок `ports_scripts` и `ports` из архива в одноимённые папки в корне карты. На XF45V проверена карта MBR с основным разделом FAT32 и меткой `EEROMS`.

~~~text
EEROMS/
├── ports_scripts/Start-SSH.sh
└── ports/emuelec-ssh-launcher/
    ├── dropbear
    ├── dropbearkey
    ├── authorized_keys
    └── password.hash
~~~

Оставьте файл выбранного способа входа или оба файла, если нужны оба способа. Безопасно извлеките карту и установите её обратно в игровой слот.

## 4. Подключите Wi-Fi и запустите SSH

1. Включите консоль и откройте **Start → Network Settings**. Включите Wi-Fi, выберите SSID и введите пароль Wi-Fi. Названия пунктов зависят от прошивки.
2. Дождитесь появления IP-адреса и запишите его. Подключите компьютер к той же локальной сети.
3. Вернитесь к списку систем и откройте **Ports → Start-SSH**. Если раздела Ports нет, проверьте структуру карты, обновите список игр или перезапустите EmulationStation.
4. Журнал `ports_scripts/Start-SSH.log` содержит IP-адрес и отпечаток ключа сервера. SSH слушает TCP `2222`.

## 5. Подключитесь с компьютера

Замените `192.168.1.42` адресом консоли. При первом подключении сравните отпечаток в запросе SSH с отпечатком в журнале.

- По ключу из папки с закрытым ключом: `ssh -i ./emuelec_ed25519 -p 2222 root@192.168.1.42`.
- По паролю: `ssh -o PreferredAuthentications=password -o PubkeyAuthentication=no -p 2222 root@192.168.1.42`. Введите пароль из шага 2.

При тайм-ауте проверьте сеть и IP-адрес. Если соединение отклонено, запустите Start-SSH и прочитайте журнал. При ошибке входа проверьте имена файлов и параметры команды. После выключения консоли SSH останавливается. После загрузки запустите его снова через Ports.

## 6. Соберите пакет самостоятельно

Установите зависимости на Ubuntu 24.04 или WSL и выполните команды из корня репозитория. Скрипт проверит исходные архивы и подпись Dropbear, соберёт libxcrypt, Dropbear и dropbearkey для ARM64 и поместит ZIP, исходники и контрольные суммы в `dist/`. Журналы сборки находятся в `build/`.

~~~bash
sudo apt-get update
sudo apt-get install -y build-essential gcc-aarch64-linux-gnu libc6-dev-arm64-cross \
    binutils-aarch64-linux-gnu ca-certificates curl gnupg file python3
bash scripts/build.sh
~~~
